# Introduction

> [!NOTE]
> This is a work-in-progress.

tmux-sesh is a simple [tmux](https://github.com/tmux/tmux) plugin that integrates [sesh](https://github.com/joshmedeski/sesh), the smart tmux session manager, with tmux.

## Dependencies

- [tmux](https://github.com/tmux/tmux)
- [zoxide](https://github.com/ajeetdsouza/zoxide)
- [sesh](https://github.com/joshmedeski/sesh)
